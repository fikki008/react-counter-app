# React Counter App

A very simple **Counter App** built with **React.js**.  
This project was created as a beginner practice to understand React state, event handling, and component structure.

---

## 🚀 Features

- Increment counter
- Decrement counter
- Reset counter
- Simple and clean UI
- Beginner-friendly code

---

## 🛠️ Tech Stack

- **React.js**
- **Vite**
- **CSS**
- **JavaScript (ES6)**
